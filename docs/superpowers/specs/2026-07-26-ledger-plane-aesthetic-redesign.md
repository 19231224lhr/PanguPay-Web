# Ledger Plane 美学重构规格

## 目标

首页负责震撼与品牌叙事，钱包负责安静、连续和精确。二者通过四环结 Logo、蓝色价值场和一次入口过渡保持连续。

## 不可变边界

- 不改变 keystore、金额、Gateway、protocol-v2、路由 URL 或后端接口。
- 不增加字体、CSS 框架、组件库或动画库。
- 总资产是总览唯一的大型视觉中心。
- 钱包内部不使用卡片堆叠、常驻呼吸、循环扫光或装饰性加载。
- 技术安全能力保留，但 FastEvidence、AssignAck、LiabilityReceipt、CFAA 与 RootID 默认只在安全页展开。

## 页面结构

```text
紧凑问候
余额价值场：总资产 + UTXO/TXCer + 发送/收款
资金状态摘要
资产列表 7/12 | 最近活动 5/12
```

桌面主导航为总览、发送、活动、安全；组织、设置、外观、语言和锁定进入账户菜单。移动底部导航为总览、发送、活动、我的。

## 视觉与运动

- 侧栏 216px，正文最大宽度 1240px。
- 标题约 32px，总资产 72–96px，分区标题约 20px。
- 普通内容使用留白与 hairline；实体 surface 只用于表单和异常。
- 首页入口 620ms；钱包内部切换 180–200ms、位移不超过 6px。
- 余额扫光只由首次快照、手动刷新或真实余额变化触发一次。
- reduced-motion 下只保留约 120ms 淡化。
